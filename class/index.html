Class Mode for teachers and career masters

How it works: make a class code (free, no sign-up). Write it on the board. Students type it in the Career Compass form. You see anonymous totals only: career families, routes and favourite subjects. No names. No answers. Nothing shows until 5 students have joined.

Ideas for a career lesson

  1. Ask each student to pick their favourite subject and use Career Compass on a phone (pairs can share).
  2. Show the class totals. Ask: which family surprised you?
  3. Pick the top three families. Open the example career pages below and read "how to get in" together.
  4. Talk about trades as well as university. Both are real routes.

Your class code works for 60 days after it was last used. Students never see other students' choices.
